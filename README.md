# 파이썬 퀴즈 게임 🎮

파이썬으로 만든 간단한 주제별 퀴즈 프로그램입니다.

## 🚀 주요 기능
- **다양한 주제**: 대한민국, 미국, 중국 관련 문제 제공
- **데이터 저장**: JSON 형식을 사용하여 퀴즈 데이터 관리
- **안정성**: 잘못된 입력에 대한 예외 처리 완료

## 🛠 사용 기술
- Python 3.x
- JSON (데이터 저장)
- Git / GitHub (버전 관리)

- 📅 프로젝트 개발 로드맵 (10 Commits)
단계	커밋 메시지 (Commit Message)	주요 구현 내용
01	docs: 초기 설정 및 README 작성	저장소 설정, 기본 구조 생성 및 첫 푸시 (완료)
02	feat: Quiz 클래스 정의	개별 퀴즈 객체화 (질문, 4개 선택지, 정답 번호)
03	data: 기본 퀴즈 데이터 구성	5개 이상의 4지선다 퀴즈 데이터 및 JSON 스키마 설정
04	feat: 메인 메뉴 및 입력 예외 처리	메뉴 선택 시스템 및 숫자/공백/빈 값 입력 방어 코드
05	feat: 퀴즈 풀기 기능 (Branch 활용)	브랜치 생성/작업/병합, 정답 확인 및 결과 표시
06	feat: 퀴즈 추가 기능 구현	사용자 입력 기반 신규 퀴즈 등록 및 JSON 저장
07	feat: 퀴즈 목록 보기 기능 구현	전체 퀴즈 리스트 출력 및 데이터 부재 시 예외 처리
08	feat: 최고 점수 기록 시스템 구현	최고 점수 비교, 갱신 및 파일 영구 저장
09	fix: 파일 손상 복구 및 비정상 종료 방지	JSON 오류 복구, Ctrl+C/EOF 예외 처리
10	docs: 최종 문서화 및 프로젝트 마무리	README 상세 업데이트 (실행 방법, 파일 구조 등)
